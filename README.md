## 🔭 What I'm Working On

### 🏫 MarkazPro — Learning Center CRM

> A real-world CRM built for IT learning centers in Uzbekistan — not just a portfolio project, but a solution to *actual* problems I've witnessed.

```
Learning centers often run on chaos:
  spreadsheets, WhatsApp messages, pen & paper.

MarkazPro brings it all into one system.
```

**Core Domain:**

```
Center
 ├── 👨‍🎓 Students
 ├── 👨‍🏫 Teachers
 ├── 📚 Courses
 ├── 👥 Groups
 ├── 🔗 Student Groups  (many-to-many with history)
 └── 💳 Payments
```

**Real business logic I'm solving:**
- 📅 Student joins mid-month → prorated payment calculation
- 💰 Pre-payment for full course duration
- 🏷️ Discount & individual pricing per student
- 🔄 Student leaves a group → re-joins later → history preserved
- 👨‍👦 Sibling students sharing phone numbers
- 📊 Multi-group enrollment with separate payment tracking
- 🏢 Multi-center architecture with data isolation per `centerId`

**Tech Stack:**

```
Backend                    Frontend
──────────────────         ──────────────────
TypeScript                 Vue 3 + Vite
Node.js + Express          TypeScript
MongoDB + Mongoose         Quasar / Nuxt
JWT Auth (A/R tokens)      Axios + Interceptors
Role-based Access          Role-based UI
Swagger / OpenAPI          Modular Routing
```

**Role System:**

```
SuperAdmin → Owner → Admin/Manager → Teacher → Student → User
```
